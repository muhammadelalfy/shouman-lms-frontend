# Components sourced through 21st.dev

These components are adapted from upstream source, rather than original visual approximations.

## Magic UI — Dillion Verma

21st.dev listings: [Shimmer Button](https://21st.dev/@dillionverma/components/shimmer-button), [Animated Grid Pattern](https://21st.dev/community/components/magicui/animated-grid-pattern), [Magic UI / Border Beam](https://21st.dev/@dillionverma/library/magic-ui).

Additional upstream source: [Blur Fade](https://github.com/magicuidesign/magicui/blob/efe76fc5755eca1142dd4f74c1d6f0ace2887e3c/apps/www/registry/magicui/blur-fade.tsx).

Pinned upstream revision: `efe76fc5755eca1142dd4f74c1d6f0ace2887e3c`.
Source: `https://github.com/magicuidesign/magicui/tree/efe76fc5755eca1142dd4f74c1d6f0ace2887e3c/apps/www/registry/magicui`.
Local files: `src/components/ui/{shimmer-button,animated-grid-pattern,border-beam,blur-fade}.tsx`.
Adaptations: semantic Next.js link variant, academy colors, geometric star tiles, viewport-triggered finite decoration and Blur Fade reveals, reduced-motion support, native CSS classes replacing upstream utility composition where appropriate. Shimmer keyframes come from `https://magicui.design/r/shimmer-button.json`.

## shadcn/ui Carousel

Listed in [21st.dev carousel collection](https://21st.dev/community/components/explore/ui-carousel).
Pinned upstream revision: `ba1503c64472b82256d9de95e2e62c5901a38e8b`.
Source: `https://github.com/shadcn-ui/ui/blob/ba1503c64472b82256d9de95e2e62c5901a38e8b/apps/v4/registry/new-york-v4/ui/carousel.tsx`.

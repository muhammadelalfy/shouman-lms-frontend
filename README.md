# Shouman LMS Frontend

Next.js 16 homepage preview sourced from `frontend/lovable-project/` and implemented in the approved local architecture. The repository contains the tested homepage, RTL Arabic shell, server-only Laravel API client, responsive design system CSS, and GitHub Actions CI.

## Checks

```bash
npm ci
npm run lint
npm run typecheck
npm test
npm run build
npm audit --omit=dev --audit-level=high
```

Cloud deployment is intentionally not configured yet.

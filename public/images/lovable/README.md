# Original Lovable assets

Sixteen JPEGs copied without modification from the client's frontend/lovable-project/src/assets.
SHA256 equality was verified for every source/copy pair. The app favicon is also
copied from the same original project. No SVG substitutes, reconstructed crops,
retouching or generated portraits are used in the active homepage.

Run node scripts/sync-lovable-assets.mjs to refresh from the untouched source.
sha256.json records the original bytes used by this delivery.

The source images themselves are low-resolution crops from the original PDF;
that softness is present in the supplied Lovable project.

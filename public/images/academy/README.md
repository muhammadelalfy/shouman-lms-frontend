# Homepage preview assets

Logo PNGs are unmodified copies of the user-provided Claude design handoff.
The SVG illustrations are original code-native branded fallbacks, generated by
`node scripts/prepare-home-assets.mjs`. They are decorative concept art, not
photographs or representations of the academy's instructor, content or mobile app.

Exact Lovable photographs could not be exported: the supplied preview returned
HTTP 401 and the shared editor reported no access on 2026-10-13. The connector
provided source markup, but binary read_file output did not preserve image bytes.
Replace these assets with approved originals when available; keep card image
dimensions to preserve the responsive layout and prevent shifts.
